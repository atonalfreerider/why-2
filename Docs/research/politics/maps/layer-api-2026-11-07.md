## 1. The model (`Model/Politics.cs`, in progress: read it again before building)

It has `History`'s shape (`Model/History.cs:18`, `:261-271`). `Path = "Data/economy/politics"`, `Get()` and `Provide(json)` parse
on any thread and swap the model in one step. `Provide` already logs each `Check()` problem as an error, so the layer must
not log them again. Times are decimal years. What the layer can read at a time `t`:

- **Streams:** `Parties` (`Side` -1 left, +1 right), `Power(party, t)` (the stated rule, 0..1), `Represented(party, t)` and
  `ElectionAt(t)` (the popular vote), `PresidentAt(t)`, `HouseAt(t)` and `SenateAt(t)`.
- **The cascade:** `OfficesAt(t)`, by `Rank` (1 the vice president, then the Speaker, the Senate leader, State, Treasury,
  Defense, the Joint Chiefs' chairman with `Military`); `Vacant` and `Acting` too.
- **The army:** `MilitaryShare["usa"]` (and ussr, russia, china, nato, wto), `Warheads`, `Navy`, `NatoMembersAt(t)` and
  `WarsawPactAt(t)`. Read any series through `Politics.At(series, t, out nearest)`: it holds or interpolates within its gaps
  and returns NaN, never a guess, past them.
- **Moments and trade:** `MomentsBetween(from, to)` (kind: law, regulation, trade, monetary, treaty or conflict),
  `TradeAt(t)`, `Partners` and `ChinaBalance`.

**Missing for this view:** the army's walls (Jev's judgments 0-4 with confidence, in `History.MoatSource`'s shape,
`History.cs:214-227`); the officials' atlas image ids (as `History.Person.Image`); the moments' affected industries; and the
head of state's own rank 0, which `HillFoundationLayer.cs:367` gives it.

## 2. The layer file: the minimal code it needs

```csharp

{

    public override IEnumerable<string> RequiredTexts => new[] { Politics.Path };
    enum Part { Streams, Marks, Bodies, Walls, Lanes, Outlines, Count }
    static readonly string[] PartNames = { "streams", "marks", "bodies", "walls", "lanes", "outlines" };
    static readonly int[] Keys = EconomyEmphasis.Keys(View, PartNames);      // read here; RegisterView below declares them
    static readonly bool SmokeRun = Environment.GetCommandLineArgs().Contains("-smoketest");
    static HillPoliticsLayer current;

    public static bool Exploded { get; private set; }                        // the cross-section open (":x" in a state)

    public static event Action Changed;                                      // the panel follows

    public override void Upload(GraphContext ctx)

        EconomyEmphasis.RegisterView(View, PartNames.Select(p => View + "." + p), Array.Empty<string>(), Array.Empty<string>(), synthesis: true);
        states = StateNames();                            // defaults plus every "show" of the tours that name the view

            k => k >= 0 && k < states.Count ? states[k] : k.ToString());

    public override void OnFocus(ViewPreset preset)
    {
        if (preset != null && preset.Id == View) { dirty = true; FlyToState(1.4f); ShowPortraits(); }
    }

    public override void Tick(GraphContext ctx, CameraRig rig)
    {
        if (LandView.PresetId != View || Politics.Get() == null) { if (content) content.SetActive(false); ShowLabels(false); return; }
        if (content == null) { content = new GameObject("Politics"); content.transform.SetParent(transform, false); }
        content.SetActive(true);
        bool pinned = !float.IsNaN(Pinned);
        float year = pinned ? Pinned : LandService.ShownYear > 0 ? LandService.ShownYear : EconomyState.Year;
        string key = year.ToString("0.000", CultureInfo.InvariantCulture) + "|" + Selected + "|" + Exploded;
        if (dirty || key != builtFor)
        {
            if (!pinned && !dirty && !HillRebuilds.Take()) return;        // a land swap: one hills layer rebuilds a frame
            dirty = false; builtFor = key; Rebuild(year);                 // Streams, Marks, Bodies, Walls, Lanes, MakeLabels
        }
        // ease the opening, Place() and Outlines() as HillHistoryLayer.cs:429-436 does

    void OnDestroy() { Clear(); if (current == this) current = null; }    // destroy owned meshes and materials (:449-482)
```

The lifecycle (`Core/GraphLayer.cs:51-85`): `GraphRoot` makes every layer of the scene by reflection and sorts them by `Order`
(`GraphRoot.cs:114-121`). `Prepare` runs on workers in tiers of `Order / 10` (`:179`), `Upload` on the main thread in order
(`:204`), `Tick` every frame (`:251`), and `OnFocus` on every layer in order (`:392`). `LandView.PresetId` is already set
then, by `LandViewLayer.OnFocus` (Order 44, `LandViewLayer.cs:210`). A panel is a `GraphModule` (`GraphRoot.cs:20-29`).

**Recommended for politics:**

- Follow the chip and the replay (`LandService.ShownYear`, else `EconomyState.Year`), and rebuild under `HillRebuilds.Take()`
  only when the land drove the change (`HillRebuilds.cs:20-28`).
- Keep a pinned year for cues and the panel, as `HillRegimeLayer.Pinned` (`:87`); unpin it at `ShowState(null)`. A cue that
  called `EconomyState.SetYear` would rebuild the land and leave the tour in that year: the tour resets it only at its start
  (`LandViewLayer.cs:162-179`).
- The chip clamps to `EconomyState.MinYear = 1950` (`EconomyState.cs:26`): 1945-1949 is reachable only by a pinned year.
- Re-fly the camera when the year moves: the crest moves about two units a year, and only the section view re-flies by itself.

## 5. Drawing: how `HillHistoryLayer` does each piece

Everything is built into `LineMeshBuilder`s in land-local coordinates. Each part becomes one mesh and one material under
`content` (`Lines`, `:484-495`): `GraphMaterials.Raw(GraphMaterials.Line(Color.white, 1, queue, false))`. `Raw` places vertices
in object space, not through the warp. The fourth argument `false` makes the line alpha-blended, never additive. The highlight
id is the part's key, `EconomyEmphasis.Id(Keys[(int)part])` (`EconomyEmphasis.cs:235`). Queues: tubes 3191, marks 3192, body
points 3193, walls 3194, outlines 3195; the occluders are at 3001, so every mark must be at 3180 or above to be hidden behind a
body (`PointBodies.cs:68-78`).

**5.1 A stream** (`:526-542`). A ring of dots every 1.3 units of z; politics centres each ring at `(xParty, yPower(t))` with
its radius from the vote.

```csharp
for (float t = span.from; t <= to + .001f; t += step)                 // step = 1.3 units of z in years
{
    string part = a.MainPartAt(t); double size = part != null ? a.SizeAt(part, t) : double.NaN;
    float r = TubeR(size), z = T(s, t);                               // .36 ∛size in .45..4; NaN draws .45 and faint (:229)
    int n = Mathf.Clamp(Mathf.RoundToInt(r * 3.6f), 5, 16);
    float alpha = (measured ? .82f : .26f) * (lit ? 1 : .3f), phase = (t * 7.3f) % 1f;   // rings offset, so no straight seams
    for (int i = 0; i < n; i++)
    {
        float ang = (i + phase) * 2 * Mathf.PI / n;
        Vector3 p = new Vector3(LaneX + Mathf.Cos(ang) * r, y + Mathf.Sin(ang) * r, z);
        b.AddSegment(p, p + Vector3.up * PointBodies.DotLength, WithAlpha(c, alpha), 2.1f, 0, id, .93f);   // a dot is a 0.3-unit dash
    }
}
```

Use `HillLandscape.Z(year)` for z (`HillLandscape.cs:206-216`: a table for 1940-2032, about two units a year). `T(story, year)`
(`:105-110`) exists only for stories before the wave. The opened view draws no tubes (`:524`): the cross-section stands alone.

**5.3 A body** (`:741-742`, `:872-889`). The parts are `ContestNetwork.Part`s (`ContestNetwork.cs:105-120`). The body must be
`Kind.Company` with `Alive = true`, or its custom parts are ignored (`Organism.cs:104`, `ContestNetwork.cs:583`).

```csharp
var parts = new List<ContestNetwork.Part>
{

    new ContestNetwork.Part(ContestNetwork.PartKind.Built, Vector3.zero, r, Vol(r), lobeTint, .8f),      // stands above
    new ContestNetwork.Part(ContestNetwork.PartKind.Debt, Vector3.zero, r2, Vol(r2), owedTint, .9f),     // hangs below

var body = new ContestNetwork.Body { Id = id, Name = name, Kind = ContestNetwork.Kind.Company, CustomParts = parts, Alive = true, Value = double.NaN };
```

- A lobe's place comes from its `PartKind`, not from `Part.Offset` (`Organism.cs:130-144`). Cash, Built, Bought and Stakes
  stand above, spread around. Debt hangs straight down, so two Debt lobes overlap. Promises are skipped.
- `LobeR(size) = clamp(2.2 ∛size, 1.6, 42)` (`:233`). A party's power or an army's share needs its own scale: a share is not a
  count.
- A body measured nowhere near the year is a grey core of 2.2 (`:629-633`), drawn at 0.55 alpha and labelled "not measured".

**5.4 The cascade.** It is new code. `Bodies()` packs a contest of three columns (holder, others, rivals) by rows of kind
(`:748-860`), not a cascade by rank. Keep its line packing (`:829-850`: each body takes `2 × foot + BodyGap`, where `foot` is
`MaxRadius` plus its ring's reach, `:749`). Lay the lines out by the foundation's ranks (`HillFoundationLayer.cs:367`): 0 head of
state, 1 vice president, 2 national executive, 3 legislature, 4 state and local; add a military rank on the army's side. The
executive goes at the top centre; each rank's line steps down by `2 × max foot + LineGap`. Record `arenaMin` and `arenaMax` for
the camera (`:862-869`).

**5.5 A ring with walls** (`:931-961`). The boundary sits at `R = MaxRadius + 4` in the x-y plane, which faces a camera on the
time axis. Each source gets one arc of strands, as thick as Jev's wall.


The ring adds `4 + 1.2 + 1.2 + 2.4 × max wall + 7` to the body's foot (`:722-728`), so neighbours stand clear of it. The
wall names stand at `(k + .5) / n` of the circle, `R + thick + 4` out, stepping outward 16, 32 and 48 px (`:1258-1275`). Only one
ring per actor stands: `ActiveMoats` takes the latest one begun (`:986-987`). `Walls()` takes `History` types, so either factor
it into a static helper that both layers call, or write the politics copy against `Politics`' own source type.

**5.6 Opening and outlines.** `explode` eases toward its target at `GraphTime.Delta / 1.6` (`:429`). `Place()` lerps each body
from its stream slice to its place (scale 0.06 to 1), turns on the occluders past 0.5 and the walls past 0.95 (`:904-919`).
`Outlines()` draws `PointBodies.Silhouette(b, shape, to, eye, id, alpha, colour, 1.4f)` per body (`:1007-1022`). They are rebuilt
only while the view stands open and after the camera has moved 2 units (`:431-436`).

**5.7 Flows at a frozen year** (`HillRegimeLayer.cs:603-613`, `:923-930`). The history view has none: every material it makes
has flow 0 (`:489`, `:880`).

```csharp
var pts = new LinePoint[20];
for (int k = 0; k < pts.Length; k++) pts[k] = new LinePoint(PathAt(k / 19f), WithAlpha(Roles.Commerce, .85f), widthPx);
b.AddFlowPath(pts, Id(Part.Lanes), .4f, startPhase);           // pulses run from the first point to the last (LineMeshBuilder.cs:130-155)
Material m = GraphMaterials.Raw(GraphMaterials.Line(Color.white, 1, queue, false, 0, .2f));   // _Flow .2: a sheen under the bloom
m.SetFloat("_FlowFreq", 1.2f); m.SetFloat("_FlowSpeed", .45f); // the shader's defaults are 60 and .35 (WhyLine.shader:9-11)
```

- **The pulse.** At fe857b9 it was `frac(phase × _FlowFreq + _WhyTime × _FlowSpeed)`, where `_WhyTime` is the scaled
  `Time.time` (`Highlighter.cs:107`). The working tree reads `WhyFlowCycles(_FlowSpeed)` instead (`WhyLine.shader:182`):
  `_WhyFlowTime`, which `FlowClock.Tick()` advances first in every `GraphRoot.Update` and nothing pauses.
- `AddSegment` never pulses, and dashes (`_Dash`) never march. The pulse rate and the speed are per material, so dollars can
  only be the width.
- **Packets are the target.** `PacketMeshBuilder.AddLane(path, PacketKind.Goods, Roles.Commerce, perSecond, speed, sizePx, id,
  offsetPx: 3, seed: s, backward: false)`, drawn with `GraphMaterials.Raw(GraphMaterials.Packets(Color.white, 1, queue))`.
  - The rate is the amount in the view's unit, e.g. one packet a second for $100B a year. Every lane of the view travels at
    one speed.
  - `backward` with `offsetPx` draws the money returning on the same arch. `PacketKind.Promise` is a contract's marching dash.
  - A lane rebuilt at another rate restarts its pattern, so cross-fade the old mesh over a year swap.
  - Keep each flow behind one helper, so it can move from `AddFlowPath` to `AddLane` without touching its callers.
  - `GraphMaterials.Packets` finds `Why/Packets` by name. A player has it only because `WhyPackets.shader` sits under
    `Resources/Shaders`, as Why/Line does.

## 7. Colours

- **The palette's source.** `EconomyStyle.Roles` (`EconomyStyle.cs:103-180`) is the only source of economy colour, written as
  `Srgb(0xRRGGBB)` (linear).
- **Encoding.** Vertex colours and the Why materials take a role as it is. Text, plates and UI take `Roles.Encoded(role)`
  (`:178`). The legend's swatches are UI colours (`UI/HudLegend.cs:205`).
- **Party roles** (POLITICS.md choice 3). Add `public static readonly Color Democratic = Srgb(0x......), Republican = ...;` in
  exactly that form: `Tools/check-palette.py` reads the targets with a regular expression (`:167-172`).
- **Measuring them.** Add the roles to `ROLES` and their touching pairs to `TOUCHING` (`check-palette.py:50-53`), and to
  `PaletteCheck.Measured` and `Touching` (`Draw/PaletteCheck.cs:103-116`). The likely pairs: Democratic-Republican,
  Democratic-People (#6796EE), Republican-Desire (#EF5B98), Republican-Conflict, each with Commerce and State. The floor is 8.
- **No colour literals.** A new layer file with any `new Color(` or `new Color32(` literal is an error in `check-palette.py`
  (`:46-47`, `:90-109`). History, Advantage and Present already fail it today (exit 1). Use `Roles.*`, `Color.Lerp`,
  `WithAlpha` and `Color.white` instead. History's `KindColor`, `PartColor` and wall gold are literals (`:235-264`, `:938`): map
  them to roles rather than copying them.
- **Military wall sources.** `HillAdvantageLayer.SourceOrder`, `SourceName` and `SourceColor` (`:1496-1509`) and
  `HillHistoryLayer.SourceWord` (`:1314-1318`) know eight corporate sources plus legitimacy, geography and allies. Any other
  source draws white and sorts last. Add `navy` (or `seaControl`), `nuclear`, `alliances` and `spending` there, so the
  history panel's reading (`HistoryPanel.cs:155-160`) names them too.
- **Bloom.** The hills bloom only above 1.1 (`GraphRoot.cs:435`). Draw data at intensity 1 at most. History's sparks and bursts
  at 1.6-1.8 (`:584`, `:976`) are deliberate glows.

## 10. Cost and frame time

- **Budgets.** A long frame is 50 ms (`LayerClock.cs:18`). The advantage view's world changes ran 130-166 ms and its settling
  52 ms against that budget (HANDOFF.md:288, :315).
- **The replay.** A replay frame waits at most 60 frames for the hills layers (`SmokeTest.cs:394`), which rebuild one a frame
  for an asynchronous land (`HillRebuilds.cs:20-28`). `-smokereplay` visits only overview, landscape, money and mobility
  (`SmokeTest.cs:403-408`): measure politics' replay cost in its own sequence.
- **History rebuilds** everything in one frame, and only when story, year, selection or opening change (`:421-427`); per frame
  it eases the opening and moves the bodies (`Place`, `:904-919`).
- **Bodies.** A measured body is 642 surface points with 3 skin points each, 2,568 dots in 2 draw calls (cloud and occluder);
  an unmeasured one 162. An `Organism` marches 642 directions through 21 field samples times its lobes: keep to about 6 lobes,
  and cache shapes by id and year if replay frames run long. History's busiest stop draws 13 bodies (Vienna, HANDOFF.md); the
  cascade, the parties and the army come to about 12-15.
- **Builders.** Size builders to their content (tubes 65,536 points, marks and walls 16,384, a body 8,192). The default is 32
  (`LineMeshBuilder.cs:57-66`): a large default, allocated for each of hundreds of small builders a year, froze the replay.
- **Outlines** are rebuilt each time the camera has moved 2 units while the view is open (`:434`), so they rebuild throughout a
  flight. Cap the bodies, or rebuild them only after the flight ends.
- **Labels.** At most 140 role labels are placed at once (60 in a headset) (`LabelSystem.cs:173`). The rest are culled by
  priority: role, plus 3 for a subject part, then `Rank`. A label that finds no free place among its fallbacks and the four
  candidate places is culled, not moved under the HUD.

## 11. Pitfalls noticed

1. **Order and the portrait cards.** `HillHistoryLayer.OnFocus` clears `HistoryPopups` for every view but its own (`:391-395`),
   and `OnFocus` runs in `Order`. A politics layer with an Order of 60 or less loses its cards on focus.
2. **An unknown view id.** `ViewPresets.Get` falls back to the overview without a word (`ViewPresets.cs:342-350`): a focus or a
   tour stop on `"politics"` before the preset exists shows the overview.
3. **Two "focused" lists.**
   - `EconomyViews.Focused` (`EconomyViews.cs:55`) and `EmphasisTable.Focused` (`EmphasisTable.cs:262-263`) differ: history is
     in the first only.
   - Without the first, the foundation's, capture's, landscape's and activity's world text shows over the view.
   - The wave and the attention cloud keep hard-coded lists of their own (`HillWaveLayer.cs:205`, `HillSocialLayer.cs:112-113`).
4. **Letter keys.** `GraphRoot` maps only the digit keys (`GraphRoot.cs:313-327`). A letter `KeyCode` on a preset only labels the
   button: Advantage's I is read by its own layer (`HillAdvantageLayer.cs:316-318`).
5. **Left and right.** From the future (yaw about 180), +x runs to the screen's left (`:748`, `:1041`). Democratic on the left
   of the screen therefore takes the higher x.
6. **Cues and the year.** A cue that moves `EconomyState.Year` rebuilds the land and leaves the tour in that year. Pin a view
   year instead (section 4).
7. **Judged labels.** `HillLabel.Provenance = Mark.Judged` drops a label under confidence 0.5 (`HillLabels.cs:264-266`). Jev's
   wall confidences use another scale: under 0.15 is uncertain (`:1312`). Keep history's convention for walls ("wall 2.4 of 4,
   uncertain").
8. **Label parts.** `LabelSystem.PartAlpha` is not wired (null: every part at 1, `LabelSystem.cs:417`), so a label's `Part` hides
   nothing yet. Hide labels by `ShowLabels(false)` and `HillLabels.Clear(this)`.
9. **Labels do not follow the bodies.** They are set at the bodies' final places while the bodies lerp in, and in the land frame
   (`HillLabels.cs:305`). Do not move or scale `content`.
10. **Layer clocks.** No layer clock may use `Time.unscaledTime`, which `HillRegimeLayer.cs:131` and `:143` use: it is not
    capture-safe. Use `FlowClock.Seconds` for motion that must never stop and `GraphTime` for the story's animations.
    `EconomyEmphasis.HighlightCheck` stops `Time.timeScale` and holds the flow clock (`:720-792`), so a check that compares
    frames must do both. Smoke frames still catch the flow clock wherever loading left it, so they differ from run to run.
11. **The model's ids.** Every data file names the country differently (us-gov, united-states, USA, us, united_states; power
    map). Agree on a join in `Politics.cs`, not in the layer.
12. **Lobe sizes.** Negative values (deficits) must be made absolute and hung below as owed; `LobeR` clamps negatives to 0
    (`:233`). Lobe sizes are volumes (`Vol`), not dollars.
13. **Settling time.** The view's own smoke frame is taken 2.6 s after a 0.6 s focus, and a state's 1.2 s after `Show`
    (`SmokeTest.cs:41`, `:246-247`). Fly in 0 s under `-smoketest` (`:326`), and let the opening settle within that time.
14. **Label stacking.** A stacking loop that raised a name to the same height forever hung the regimes view
    (`HillRegimeLayer.cs:448`; the same in `HillSocialLayer.cs:494`). Bound every stacking loop: `Steps` makes four steps at most.
15. **Screen edges.** The year chip, the panels' side column, `TourPictures` (cards beside the narration, being edited) and
    `HistoryPopups` all compete for the left and right edges during a tour. Check frames with `-smoketour`.
